APK para Android

Instale no seu dispositivo

O APK será gerado automaticamente via GitHub Actions. Clique no botão abaixo para ver os builds disponíveis:

Ver Builds no GitHub Actions

Ou construa localmente (requer Java 17+): 

# Instale Java 21
winget install EclipseAdoptium.Temurin.21.JDK

# Build
cd android
./gradlew assembleDebug
# APK em: app/build/outputs/apk/debug/app-debug.apk
